How to prepare the drawing

  • Draw every area as a closed polyline on its own layer: the plot boundary, roads, parks, water, beach, services plots, and one layer per product (villa plots, chalet blocks, hotel plot and so on). Circles are read too, and blocks (inserts) are exploded.
  • Building footprints are optional, on a layer of their own. Each one takes the product of the plot it stands in. Put the floors in the layer name (for example BLDG G+2 or BLDG 4F) or set them on the next page.
  • Plots without footprints are filled with the building library's types, within the height limits, so a land-use plan alone still gets a built area.
  • Units in metres (the drawing's units setting is used when it is set). AutoCAD: Save As, DXF; DWG cannot be read.
  • On the next page you check what each layer is and which boundary edge faces the sea or main road.
